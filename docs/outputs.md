# Outputs reference

All of these files are generated by `python run_all.py`, except the HTML dashboard, which comes from `python -m src.export_html`.

## Figures (`outputs/`)

| File | Content |
|---|---|
| `01_offensive_line_ranking.png` | Each offensive line's RMST gap vs the NFL average |
| `02_pass_rush_team_ranking.png` | RMST allowed by each defense (shorter = better rush) |
| `03_top_pass_rushers.png` | Top 15 rushers by rate of reaching < 2 yd from the QB |
| `04_pocket_clock_by_rushers.png` | Kaplan-Meier curves for 4 rushers or fewer, 5, and 6+ |
| `05_pocket_clock_man_vs_zone.png` | Kaplan-Meier curves for man and zone coverage |
| `06_cpt_over_expected.png` | Actual − expected RMST per offensive line (Cox model) |
| `07_qb_internal_clock.png` | For each QB (≥ 80 plays): median time to throw vs RMST |
| `08_fastest_sack.gif` | Animation of the fastest sack (CPT ≥ 0.5 s) |
| `pocket_clock_dashboard.html` | Standalone dashboard: interactive ranking, per-team pocket clock and replays of the 3 fastest sacks |

## Rankings (`outputs/ranking_*.csv`, `qb_clock.csv`)

**`ranking_offensive_lines.csv`** and **`ranking_pass_rush_teams.csv`**

| Column | Description |
|---|---|
| `team` | Team |
| `n` | Number of plays |
| `rmst` | Mean clean-pocket time over 3 s (s) |
| `clean_2.5s` | Share of pockets still clean at 2.5 s (KM) |
| `sack_rate` | Share of plays ending in a sack |
| `rank` | Rank (1 = longest RMST) |

**`ranking_over_expected.csv`**: columns `team`, `n`, `rmst`, `expected` (mean RMST predicted by the Cox model) and `over_expected` (= `rmst − expected`).

**`ranking_rushers.csv`**

| Column | Description |
|---|---|
| `rusher`, `rusherId` | Player |
| `rushes` | Number of rushes |
| `wins` / `win_rate` | Number and share of plays where he is first to enter the radius |
| `reach_rate` | Share of rushes where he enters the radius (sort key) |
| `mean_entry_t` | Mean entry time (s), when he gets there |
| `entry_speed` | Mean speed at entry (yd/s) |
| `cpt_when_first` | Mean CPT on plays where he arrived first |

**`ranking_blockers.csv`**: columns `blocker`, `blocker_pos` (alignment position), `team`, `duels`, `beaten_rate` (share of duels where the assigned rusher enters the radius) and `mean_entry_t`.

**`qb_clock.csv`**: columns `qb`, `n`, `throw_t` (median time to throw or sack), `rmst` and `pressured` (share of uncensored plays).

**`robustness_ol_ranking.csv`**: each offensive line's rank with a 1.5, 2 and 3 yd radius.

## Validation (`outputs/validation_*.csv`)

| File | Grouping |
|---|---|
| `validation_by_result.csv` | `passResult` (C = complete, I = incomplete, IN = interception, S = sack, R = QB run) |
| `validation_by_blitz.csv` | 3-4, 5 or 6+ rushers |
| `validation_by_play_action.csv` | Play action (0 or 1) |
| `validation_by_coverage.csv` | Man, zone or other |

These four files have the columns `n`, `RMST_3s`, `clean_2.5s`, `censored` (censored share) and `median_throw_t` (median play duration).

- **`validation_pff.csv`**: agreement with PFF pressures. It holds the conditional probabilities, precision, recall and φ correlation.
- **`validation_result_vs_cpt.csv`**: completion rate and yards per pass for each 0.5 s CPT bucket.

## Cache (`cache/`)

| File | Content |
|---|---|
| `tracking.parquet` | Normalized tracking restricted to [snap, end], with `snap_frame`, `end_frame` and `t` |
| `tracking_debug.parquet` | Same in `DEBUG=1` mode (5 games) |
| `cpt_table.parquet` | The `tab` table: one row per play |
| `duels.parquet` | The `duels` table: one row per (play, rusher) |

### Main columns of `cpt_table.parquet`

| Column | Description |
|---|---|
| `gameId`, `playId` | Play key |
| `cpt` | Clean Pocket Time (s) |
| `censored` | `True` if no rusher entered the radius |
| `duration` | Length of the snap → end window (s) |
| `cpt_1.5`, `cpt_2.0`, `cpt_3.0` | CPT with other radii |
| `first_rusher`, `first_rusherId`, `first_entry_speed` | First rusher to enter the radius |
| `first_blocker`, `first_blockerId`, `first_blocker_pos` | Blocker assigned to that rusher |
| `qb`, `qbId` | Quarterback |
| `n_rushers`, `n_blockers` | Number of rushers and blockers (PFF) |
| `pff_pressure` | At least one PFF hit, hurry or sack |
| `possessionTeam`, `defensiveTeam`, `down`, `yardsToGo`, `passResult`, `playResult`, `offenseFormation`, `pff_passCoverage`, `pff_passCoverageType`, `pff_playAction`, `dropBackType`, `defendersInBox`, `quarter` | Play context, taken from `plays.csv` |

### Columns of `duels.parquet`

The columns are `rusherId`/`rusher`, `blockerId`/`blocker`/`blocker_pos`, and `entry_t` and `entry_speed` (NaN if the rusher never enters the radius). There is also `won_first`, the blocker's PFF flags (`pff_beatenByDefender`, `pff_hurryAllowed`, `pff_sackAllowed`, `pff_hitAllowed`) and the play context (`possessionTeam`, `defensiveTeam`, `cpt`, `censored`, `n_rushers`).
